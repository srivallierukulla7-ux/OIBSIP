## 🚀 Projects Overview

### 1. PodWave Landing Page (Project 1)
A strictly minimalist landing page for a podcast platform called PodWave.
- **Key Features:** Whitespace-first design, generous spacing (160px gap), and refined typography using the 'Inter' font.
- **Goal:** To create a premium, architectural look that focuses on readability and clean visual structure.
- **Live Demo:** [srivalli-landingpage.netlify.app](https://srivalli-landingpage.netlify.app/)
- **Tech Stack:** HTML5, CSS3.

### 2. Personal Portfolio (Project 2)
My personal portfolio website featuring a soft, professional, and elegant aesthetic.
- **Key Features:** Lavender-themed UI with frosted glass navigation, smooth animations (including a morphing hero image container), and clean project displays.
- **Goal:** To showcase my academic background, technical skills (Python, Java, C), and personal projects in a neat and simple way.
- **Live Demo:** [srivalli-portfolio.netlify.app](https://srivalli-portfolio.netlify.app/)
- **Tech Stack:** HTML5, CSS3 (Instrument Serif & Inter fonts), JavaScript.

### 3. Temperature Converter (Project 3)
A simple and functional tool to convert temperatures between different units.
- **Key Features:** Supports Celsius, Fahrenheit, and Kelvin conversions. Features a clean, card-based UI and real-time result display.
- **Goal:** To implement logical programming using JavaScript for real-time data handling and unit conversion.
- **Live Demo:** [srivalli-tempconvert.netlify.app](https://srivalli-tempconvert.netlify.app/)
- **Tech Stack:** HTML5, CSS3, JavaScript.
